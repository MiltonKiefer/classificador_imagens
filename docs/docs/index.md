# Classificador de imagens CIFAR-10

## Description

Projeto de classificação de imagens com uma CNN em TensorFlow/Keras. Consulte
[Primeiros passos](getting-started.md) para instalar, executar o pipeline e
rodar os testes.

## Commands

Com o ambiente virtual ativo:

- `python -m classificador_imagem.run`: treina, avalia e mostra os gráficos e as
  previsões.
- `python -m pytest tests -q`: executa os testes automatizados.
